# Travel Website Landing Page

This is a simple landing page for a fictional travel agency, created as an exercise to practice and demonstrate responsive design skills. The project's main focus is to ensure the website looks great on all devices, from large desktop monitors to mobile phones.

Design: https://www.figma.com/design/18Xe5OMmaeAh4jqzVBLXYE/%E1%83%A4%E1%83%98%E1%83%9C%E1%83%90%E1%83%9A%E1%83%A3%E1%83%A0%E1%83%98-HTML-CSS?node-id=0-1&t=Ua2Q1R0GjDMyomCL-1

### ✨ Project Goals

*   **Practicing Responsive Design:** Using CSS Flexbox and Grid to create a flexible and adaptive layout.
*   **Applying Media Queries:** Customizing styles for various screen resolutions.
*   **Working with Vanilla HTML & CSS:** Honing fundamental web development skills without relying on frameworks.

### 🚀 Tech Stack

*   HTML5
*   CSS3

### 📱 How to Check Responsiveness

1.  Open the [live demo](https://maribukh.github.io/Travel-Website/) in a desktop browser.
2.  Open the developer tools (usually by pressing the `F12` key).
3.  Toggle the device toolbar (often a phone/tablet icon) and select different devices to see how the layout adapts.
